- 根据指定的元素值 e ，查找顺序表中第一个和 e 相等的元素。若查找成功，则返回该元素在表中的位置序号；若查找失败，则返回0.
```c
int LocateElem(SqList L, ElemType e){ // 在顺序表 L 中查找值为 e 的数据元素，返回其序号
    for(int i=0; i<L.length; i++)
        if(L.data[i]==e)
            return i+1; // 查找成功，返回序号 i+1
    return 0; // 查找失败，返回 0
}
```
- 最好情况：目标元素在表头，时间复杂度为 $O(1)$；最坏情况：元素在表尾，为 $O(n)$；平均情况为 $O(n)$。
