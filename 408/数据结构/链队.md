- **链队：**
- 采用链式存储结构实现的队列，其实和单链表差不多，只不过一个链队需要两个分别指示队头和队尾的指针（分别称为头指针和尾指针）才能唯一确定。

```cpp
typedef struct LinkNode { // 链式队列结点
    ElemType data;
    struct LinkNode *next;
} LinkNode;

typedef struct { // 链式队列
    LinkNode *front; // 队头指针
    LinkNode *rear; // 队尾指针
} LinkQueue;
```

【注意】和单链表一样，可以分为带头结点和不带头结点的方式。
