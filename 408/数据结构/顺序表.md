- 指的是用==一组地址连续的存储单元==依次存储线性表的数据元素
- 特点是逻辑上相邻的数据元素，其物理次序也是相邻的
- 有==随机存取==的特性：能立刻获取某个元素

| 数组下标      | 顺序表           | 内存地址                                |
| --------- | ------------- | ----------------------------------- |
| 0         | $a_1$         | LOC(A)                              |
| 1         | $a_2$         | LOC(A)+sizeof(ElemType)             |
| ...       | ...           | ...                                 |
| i-1       | $a_i$         | LOC(A)+(i-1)*sizeof(ElemType)       |
| ...       |               |                                     |
| MaxSize-1 | $a_{MaxSize}$ | LOC(A)+(MaxSize-1)*sizeof(ElemType) |

### 静态分配
```c
#define MAXSIZE 100

typedef struct {
    ElemType data[MaxSize];
    int length;
} SqList;

int main(){
    SqList L; // 定义一个顺序表
    操作它;
    return 0;
}
```
### 动态分配

```c
typedef struct{
    ElemType *data; // 指向动态数组的指针
    int length; // 顺序表当前长度
    int MaxSize; // 顺序表最大容量
} SeqList;

int main(){
    SeqList L; // 定义一个顺序表
    操作它;
    return 0;
}
```
