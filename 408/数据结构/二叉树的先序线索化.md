
```cpp
ThreadNode *pre = NULL; // 定义指针指向当前访问结点的前驱

void PreThread(ThreadTree T) {
    if (T != NULL) {
        visit(T); // 访问根结点
        if (T->tag == 0)//防止出现原地转圈
	        PreThread(T->lchild); // 先序遍历左子树
        PreThread(T->rchild); // 先序遍历右子树
    }
}

void visit(ThreadNode *p) {
    if (p->lchild == NULL) { // 左子树为空，建立前驱线索
        p->lchild = pre;
        p->ltag = 1;
    }
    if (pre != NULL && pre->rchild == NULL) {
        pre->rchild = p; // 建立前驱结点的后继线索
        pre->rtag = 1;
    }
    pre = p; // 标记当前结点成为刚刚访问过的结点
}
```
- **先序线索二叉树找先序前驱**

1. 若 `p->ltag == 1`，则表明其前驱 `pre = p->lchild`。  
2. 若 `p->ltag == 0`，则表示其 `lchild` 指向其左孩子，并不是先序前驱。

【问题】我们想要找前驱，但是 `p` 指向的结点只有左、右两个指针指向孩子结点，且先序是按照“根结点、左子树、右子树”的顺序，其孩子结点必然是其先序序列中的后继结点。

→ 所以在普通二叉链表结构中，并不方便找到某结点的先序前驱。

【解决】我们可以在结点类型中再设置一个父结点指针，用来往回找。
3. 如果能找到 `p` 的父结点，且 `p` 是左孩子，则 `p` 的父结点即为其前驱。  
4. 如果能找到 `p` 的父结点，且 `p` 是右孩子，其左兄弟为空，则 `p` 的父结点即为其前驱。  
5. 如果能找到 `p` 的父结点，且 `p` 是右孩子，其左兄弟非空，则 `p` 的前驱为左兄弟子树中最后一个被先序遍历的结点。  
6. 若 `p` 是根结点，则 `p` 没有先序前驱。
