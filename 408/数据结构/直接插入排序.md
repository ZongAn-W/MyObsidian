## 直接插入排序

> [!question] 思考
> 如果给你一串数字，你能想到如何进行排序。

→想想你**打牌摸牌**的时候，每一次都是**抽一张牌**然后**插入**到你已经整理好的牌型中。

- **插入排序**：每次将一个**待排序**的记录**按其关键字大小插入**到前面**已经排好序的子序列**。
- **直接插入排序**：每一次将**一个关键字通过顺序查找比较插入**到前面**已经有序的子序列**。
→假定初始序列为49, 38, 65, 97, 76, 13, 27, 49。按照**直接插入排序**进行排序。

> [!note] 思路描述
> 确定一个关键字a之后，在已排序子序列中找到正确的**插入位置k**，然后将子序列中k位置及之后位置上的元素**后移**一个位置，最后将a放入位置k。

→算法过程中最重要有两点：①通过比较找到位置k；②移动元素。
→排序49, 38, 65, 97, 76, 13, 27, 49。

```c
void InsertSort(int A[], int n){
    int i, j, temp;
    for(i=1; i<n; i++)      //将各元素插入到已排好序的序列中
    {
        if(A[i]<A[i-1]){    //若A[i]关键字小于前驱
            temp=A[i];      //用temp暂存A[i]，防止数据移动造成数据丢失
            for(j=i-1; j>=0 && A[j]>temp; --j)  //检查所有前面已排好序的元素
                A[j+1]=A[j];    //所有大于temp的元素都向后移动位置
            A[j+1]=temp;    //复制到插入位置
        }
    }
}
```

```c
void InsertSort(ElemType A[], int n){
    int i,j;
    for(i=2;i<=n;i++) //依次将A[2]～A[n]插入前面已排序序列
        if(A[i]<A[i-1]){ //若A[i]关键码小于其前驱，将A[i]插入有序表
            A[0]=A[i]; //复制为哨兵，A[0]不存在元素
            for(j=i-1; A[0]<A[j];--j) //从后往前查找待插入位置
                A[j+1]= A[j]; //向后挪位
            A[j+1]= A[0]; //复制到插入位置
        }
}
```

- **空间复杂度**：仅使用了常数个辅助单元，因而空间复杂度为O(1)。
- **时间复杂度**：主要来自对比关键字、移动元素。
   - **最好情况下**：表中元素已经有序，此时每插入一个元素，都只需比较一次而不用移动元素。若有n个元素则需n-1次比较，因而时间复杂度为 O(n)。
   - **最坏情况下**：表中元素顺序刚好与排序结果中的元素顺序相反（逆序），总的比较次数达到最大，时间复杂度为O(n²)。
   - 平均时间复杂度：O(n²)。
- **稳定性**：稳定
