## 双亲表示法（顺序存储）

以一组连续的存储单元存储树的结点，每个结点除了数据域 `data` 外，还附设一个 `parent` 域用以指示其双亲结点的位置，利用了每个结点（除根以外）只有唯一双亲的性质。

```cpp
// 双亲表示法的存储结构描述如下
#define MAX_TREE_SIZE 100 // 树中最多结点数

typedef struct { // 树的结点定义
    ElemType data; // 数据元素
    int parent; // 双亲位置域
} PTNode;

typedef struct { // 树的类型定义
    PTNode nodes[MAX_TREE_SIZE]; // 双亲表示
    int n; // 结点数
} PTree;
```

- 在这种存储结构下，求节点的双亲十分方便，也容易求树的根
- 但是求节点的孩子时需要遍历整个结构

## 孩子表示法

（顺序存储＋链式存储）：顺序存储各结点，每个结点中保存孩子链表头指针。

将每个结点的孩子结点都用单链表链接起来形成一个线性结构，此时 $n$ 个结点就有 $n$ 个孩子链表（叶子结点的孩子链表为空表）。
> [!warning] 注意
> 这种方式找孩子结点还方便，但是找双亲就需要遍历，不方便。

```cpp
// 孩子表示法的存储结构描述如下
struct CTNode {
    int child; // 孩子结点在数组中的位置
    struct CTNode *next; // 下一个孩子
};

typedef struct {
    ElemType data;
    struct CTNode *firstChild; // 第一个孩子
} CTBox;

typedef struct {
    CTBox nodes[MAX_TREE_SIZE];
    int n, r; // 结点数和根的位置
} CTree;
```

## 孩子兄弟表示法（链式存储）

- 又称二叉树表示法，即以二叉链表作为树的存储结构。
- 每个结点包括三部分内容：结点值、指向结点第一个孩子结点的指针，以及指向结点下一个兄弟结点的指针。

> [!warning] 注意
> 和存二叉树的二叉链表形式一样，只是指针的含义不同。

```cpp
typedef struct CSNode {
    ElemType data;
    struct CSNode *firstchild, *nextsibling; // 第一个孩子和右兄弟指针
} CSNode, *CSTree;
```

> [!tip] 总结
> 由于二叉树和树都可以用二叉链表作为存储结构，因此以二叉链表作为媒介可以导出树与二叉树的一一对应关系，即给定一棵树，可以找到唯一的一棵二叉树与之对应。从物理结构上看，它们的二叉链表是相同的，只是解释不同而已。

- **树和二叉树相互转换**

（1）将同一结点的各孩子结点用线串起来；
（2）除了第一个结点以外，到其余结点的分支从左往右都剪掉；
（3）调整结点，使之符合二叉树的层次结构。
