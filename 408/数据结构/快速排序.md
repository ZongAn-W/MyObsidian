## 快速排序

- **快速排序**：在待排序表 L[1...n] 中任取一个元素**pivot作为基准**，通过一趟排序将待排序表划分为**独立的两部分L[1...k-1]和L[k+1...n]**，使得**L[1...k-1]**中的所有元素**小于pivot**，**L[k+1...n]**中的所有元素**大于pivot**，则 pivot 放在了其最终位置L[k]上，这个过程称为**一趟快速排序**。然后分别递归地对两个子表重复上述过程，直至每部分内只有一个元素或空为止，即所有元素放在了其最终位置上。
→原始序列：49、38、65、97、76、13、27、49

```c
void QuickSort(int A[], int low, int high){
    if(low<high){
        int pivotpos=Partition(A, low, high);
        QuickSort(A, low, pivotpos-1);
        QuickSort(A, pivotpos+1, high);
    }
}
int Partition(int A[],  int low,  int high){
    int pivot=A[low];
    while(low<high){
        while(low<high && A[high]>=pivot)   --high;
        A[low]=A[high];
        while(low<high&&A[low]<=pivot)   ++low;
        A[high]=A[low];
    }
    A[low]=pivot;
    return low;
}
```

> [!warning] 注意
> 把n个元素组织成二叉树，二叉树的**深度就是递归调用的层数**。n个结点的二叉树的最小高度=$\lceil\log_2(n+1)\rceil$，最大高度为n。

> [!warning] 注意
> 算法效率和选中的枢轴有关，如果能将序列**均匀**的分为两部分则好，不均匀分则差。

- **空间复杂度(O(递归层数))**：
   - **最好情况**：O(log₂n)；
   - **最坏情况**：O(n)；
   - **平均情况**：栈的深度为O(log₂n)。
- **时间复杂度(O(n*递归层数))**：
   - **最好情况**：O(nlog₂n)；【选枢轴元素能将序列划分成均匀的两部分】
   - **最坏情况**：O(n²)；【序列原本就有序】
   - **平均情况**：O(nlog₂n)。
- **稳定性**：不稳定。

> [!warning] 注意
> 快速排序是所有内部排序算法中平均性能最优的排序算法。
