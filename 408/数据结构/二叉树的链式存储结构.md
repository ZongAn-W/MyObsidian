- **链式存储**：由于顺序存储的空间利用率较低，因此二叉树一般都采用链式存储结构，用链表结点来存储二叉树中的每个结点。结点包含数据域 `data`、左指针域 `lchild` 和右指针域 `rchild`。

【注意】如果一个结点没有左孩子或右孩子，就将指向其孩子结点的指针设为 `NULL`。

| `lchild` | `data` | `rchild` |
|:---:|:---:|:---:|
- **结构描述**
```cpp
typedef struct BiTNode {
    ElemType data; // 数据域
    struct BiTNode *lchild, *rchild; // 左右孩子指针
} BiTNode, *BiTree;
```

【总结】一个含有 $n$ 个结点的二叉链表中，共有 $2n$ 个指针域。除根结点外，共有 $n-1$ 个结点会被其父结点的指针域指向，因此含有 $n+1$ 个空链域。

【思考】要根据实际应用场合（二叉树的形态和需要进行的运算）来选择合适的存储结构。比如在此种二叉链表中，无法快速找到某结点的父结点，可在结点类型描述中添加父结点指针，指向结点的父结点。

```cpp
typedef struct BiTNode {
    ElemType data; // 数据域
    struct BiTNode *lchild, *rchild; // 左右孩子指针
} BiTNode, *BiTree;

// 定义一棵树
BiTree root = NULL;

// 插入根结点
root = (BiTree)malloc(sizeof(BiTNode));
root->data = x;
root->lchild = NULL;
root->rchild = NULL;

// 插入新结点
BiTNode *p = (BiTNode *)malloc(sizeof(BiTNode));
p->data = x;
p->lchild = NULL;
p->rchild = NULL;
root->lchild = p; // 作为根结点的左孩子
```
