- 为了解决假溢出问题提出了循环队列的概念
- 初始时：Q.front = Q.rear = 0
- 队首指针进1：Q.front = (Q.front+1) % Maxsize
- 队尾指针进1：Q.rear = (Q.rear+1) % Maxsize
- 队列长度：(Q.rear + Maxsize - Q.front) % Maxsize

对于循环队列不能用头尾指针值是否相同来判断队列是空还是满
### 区分队空还是队满的3种处理方式
（1）牺牲一个单元来区分队空还是队满，入队时少用一个队列单元，即队列大小为m时，有m-1个元素就认为是队满，判断队空的条件不变（头尾指针的值相同）；当尾指针在循环意义上加一后等于头指针则认为队满
- 队空的条件：Q.front == Q.rear
- 队满的条件：(Q.rear+1) % Maxsize == Q.front

（2）类型中增设标识元素个数的数据成员
- 队空的条件：Q.size == 0
- 队满的条件：Q.size == Maxsize

（3）类型中增设tag数据成员，以区分队满还是队空

### 循环队列的操作
入队和出队操作：
```cpp
Status EnQueue(SqQueue &Q, ElemType x) {
    if ((Q.rear + 1) % MaxSize == Q.front)
        return ERROR; // 队满报错
    Q.data[Q.rear] = x; // 将 x 插入队尾
    Q.rear = (Q.rear + 1) % MaxSize; // 队尾指针加 1 取模
    return OK;
}

Status DeQueue(SqQueue &Q, ElemType x) {
    if (Q.front == Q.rear)
        return ERROR; // 队空报错
    x = Q.data[Q.front]; // 保存队头元素
    Q.front = (Q.front + 1) % MaxSize; // 队头指针加 1 取模
    return OK;
}
```

- **获取队头元素：**

```cpp
Status GetHead(SqQueue Q, ElemType &x) {
    if (Q.rear == Q.front)
        return ERROR; // 队空报错
    x = Q.data[Q.front]; // 保存队头元素
    return OK;
}
```

- **求队列长度：**

```cpp
int QueueLength(SqQueue Q) { // 返回 Q 的元素个数，即队列的长度
    return (Q.rear - Q.front + MaxSize) % MaxSize;
}
```
