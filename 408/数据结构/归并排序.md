## 归并排序

- **算法思想**：把两个或多个**已经有序**的序列合并成一个。

> [!warning] 注意
> 二路归并，就是将两个**有序序列合并**，每选出一个元素需对比关键字1次。m路归并每选出一个元素需要对比m-1次。

> [!tip] 总结
> 两两比较的序列，一旦有一个序列所有元素都已合并，则无需再比，直接将另一个序列的元素依次合并进去。

> [!tip] 总结
> 如果要归并一个无序序列，即把这序列分成两个序列合并，则还原成递归归并两个无序子序列，以此类推，可使用递归，递归到最后分成的子序列只是一个元素（当然有序）再依次合并。

```c
int *B=(int *)malloc(n*sizeof(int));//辅助数组B

void Merge(int A[], int low, int mid, int high){
    int i, j, k;
    for(k=low; k<=high; k++)
        B[k]=A[k];  //将A中所有元素复制到B中
    for(i=low, j=mid+1, k=i; i<=mid&&j<=high; k++){
        if(B[i]<=B[j])
            A[k]=B[i++];  //将较小值复制到A中
        else
            A[k]=B[j++];
    }
    while(i<=mid) A[k++]=B[i++];
    while(j<=high) A[k++]=B[j++];
}

void MergeSort(int A[], int low, int high){
    if(low<high){
        int mid=(low+high)/2;  //从中间划分
        MergeSort(A,low,mid);  //对左半部分归并排序
        MergeSort(A,mid+1,high);  //对右半部分归并排序
        Merge(A,low,mid,high); //归并
    }
}
```

- **时间复杂度**：O(nlog₂n)
   - →二路归并的全部过程形态上是一棵倒立的二叉树，初始序列是叶子结点。
   - →根据二叉树的第h层最多有 $2^{h-1}$ 个结点，若树高为h，则应满足 $n\le 2^{h-1}$，即 $h-1=\lceil\log_2n\rceil$。
   - →每趟归并时间复杂度为O(n)，总共需要进行归并的趟数等于归并树的高h-1。
- **空间复杂度**：主要来自于辅助数组B，O(n)。
- **稳定性**：稳定。
