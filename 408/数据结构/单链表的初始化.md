### 不带头结点
```c
// 不带头结点
Status InitList(LinkList &L){
    L=NULL; // 表示空表，还未指向任何结点，并且防止脏数据
    return OK;
}
```

### 带头结点
```c
// 带头结点
Status InitList(LinkList &L){ // 构造一个空的单链表 L
    L=(LNode *)malloc(sizeof(LNode)); // 生成新结点作为头结点，用头指针 L 指向头结点
    if(L==NULL) return ERROR; // 内存不足，分配失败
    L->next=NULL; // 头结点的指针域置空
    return OK;
}
