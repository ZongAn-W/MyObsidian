- 利用[[栈]]底位置相对不变的特性，两顺序[[栈]]共享一个一维数组空间，将两个[[栈]]的[[栈]]底分别设置在共享空间的两端，两个[[栈]]顶向共享空间的中间延伸

- **共享栈描述：**

```cpp
#define MaxSize 10 // 定义栈中元素的最大个数

typedef struct {
    ElemType data[MaxSize]; // 静态数组存放栈中元素
    int top0; // 0 号栈栈顶指针
    int top1; // 1 号栈栈顶指针
} ShStack;

// 初始化栈
void InitStack(ShStack &S) {
    S.top0 = -1;
    S.top1 = MaxSize;
}
```

【总结】两个栈的栈顶指针都指向栈顶元素，`top0 == -1` 时 0 号栈为空，`top1 == MaxSize` 时 1 号栈为空；仅当两个栈顶指针相邻（`top1 - top0 == 1`）时，判断为栈满。当 0 号栈进栈时，`top0` 先加 1 再赋值；1 号栈进栈时，`top1` 先减 1 再赋值；出栈时则刚好相反。

共享栈是为了**更有效地利用存储空间**，两个栈的空间相互调节，只有在整个存储空间被占满时才发生上溢。
