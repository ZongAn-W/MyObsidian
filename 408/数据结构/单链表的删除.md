- 删除单链表中指定位置的元素，同插入元素一样，首先应该找到该位置的前驱结点
```c
Status ListDelete(LinkList &L, int i, ElemType &e){ // 有头结点的单链表，删除第 i 个元素
    LNode *p=L;
    int j=0; // 当前 p 指向的是第几个结点
    while(p!=NULL && j<i-1){ // 循环找到第 i-1 个结点
        p=p->next;
        j++;
    }
    if(p==NULL || p->next==NULL || j>i-1) return ERROR; // i 值不合法，i>n 或 i<1
    LNode *q=p->next; // 临时保存被删除结点的地址以备释放
    e=q->data; // 用 e 返回元素的值
    p->next=q->next; // 将 *q 结点从链中断开
    free(q); // 释放删除结点的空间
    return OK;
}
```

### 指定结点的删除
- 删除指定结点，并不知道头指针
- 如果删除的指定结点为表尾结点，下述代码无法工作
```c
Status DeleteNode(LNode *p){
    if(p==NULL) return ERROR;
    LNode *q=p->next; // 令 q 指向 *p 的后继结点
    p->data=p->next->data; // 和后继结点交换数据域
    p->next=q->next;
    free(q);
    return OK;
}
```
