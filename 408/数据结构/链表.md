- **链表**：用一组任意的存储单元存储线性表的数据数据元素（这组存储单元可以是不连续的）
- **结点node**：对于数据元素来说，除了存储其本身的信息之外，还需存储一个指示其直接后继的位置。node包括数据域和指针域
- **单链表**：由于每个节点中只包含一个指针域，故又称线性链表
```c
typedef struct LNode{
    ElemType data; // 结点的数据域
    struct LNode *next; // 结点的指针域
} LNode, *LinkList; // LinkList 为指向结构体 LNode 的指针类型

LNode *p = (LNode*)malloc(sizeof(LNode));
//增加一个新的node，在内存中申请一个结点所需空间，并用指针p指向这个结点
```
 - **头指针**：标识一个单链表，如单链表L，头指针为NULL时表示一个空表
 - **头结点**：在单链表第一个结点之前附加一个结点，不附加数据，其指针域指向第一个数据
- 添加头结点的原因：对链表第一个位置的操作与其他位置上操作的统一；如果有头结点，无论是不是空表，头指针都不为NULL
