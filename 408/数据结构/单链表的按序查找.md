### 带头结点的查找
- 根据给定的结点位置序号 i ，在链表中获取该结点的值
```c
Status GetElem(LinkList L, int i, ElemType &e){
    LNode *p=L->next;
    int j=1; // 初始化，p 指向首元结点，计数器初值赋为 1
    while(p!=NULL && j<i){ // 顺链域向后扫描，直到 p 为空或 p 指向第 i 个元素
        p=p->next; // p 指向下一个结点
        ++j; // 计数器相应加 1
    }
    if(!p || j>i) return ERROR; // i 值不合法，i>n 或 i<=0
    e=p->data; // 取第 i 个结点的数据域
    return OK;
}
