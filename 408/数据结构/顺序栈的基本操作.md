- **初始化：**
```cpp
void InitStack(SqStack &S) {
    S.top = -1; // 初始化栈顶指针
}
```

【总结】这时候 `top` 不指向任何空间，表示栈顶元素不存在，栈中无元素。

- **判空**
```c++
bool StackEmpty(SqStack S) {
    if (S.top == -1) // 如果栈空
        return true;
    else // 如果栈不空
        return false;
}
```

- **进栈**
```c++
bool Push(SqStack &S, ElemType x) {
    if (S.top == MaxSize - 1) // 如果栈满，报错
        return false;
    S.data[++S.top] = x; // 指针先加 1，再将数据入栈
    return true;
}
```

- **出栈**
```cpp
bool Pop(SqStack &S, ElemType &x) {
    if (S.top == -1) // 如果栈里没数据了，报错
        return false;
    x = S.data[S.top--]; // 先出栈，指针再减 1
    return true;
}
```

- **读栈顶元素**
```cpp
bool GetTop(SqStack S, ElemType &x) {
    if (S.top == -1)
        return false; // 栈空，报错
    x = S.data[S.top]; // x 记录栈顶元素
    return true;
}
```
