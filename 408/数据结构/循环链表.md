### 循环单链表
- 表中最后一个结点的指针不是NULL，而改为指向头结点，从而整个链表形成一个环

- 初始化
```c
Status InitLinkList(Linklist &L){
    L=(LNode *)malloc(sizeof(Node)); // 分配一个头结点
    if(L==NULL) return ERROR; // 内存不足，分配失败
    L->next=L; // 头结点 next 指向头结点
    return OK;
}
```

### 循环双链表
• 初始化
```c
Status InitDLinkList(DLinklist &L){
    L=(DNode *)malloc(sizeof(DNode)); // 分配一个头结点
    if(L==NULL) return ERROR; // 内存不足，分配失败
    L->prior=L; // 头结点 prior 指向头结点
    L->next=L; // 头结点 next 指向头结点
    return OK;
}
```
