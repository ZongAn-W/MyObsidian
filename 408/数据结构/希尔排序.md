## 希尔排序

> [!question] 思考
> 对于直接插入排序而言，当**序列有序时效率就很高**，并且如果序列是基本有序的状态时，效率也算还不错，需要移动的次数大大减少。

→有两个方式能让效率提高：①数据变少；②逐渐有序。为此引入希尔排序。

- **希尔排序**：又称**缩小增量排序**，本质上还是插入排序，只是需要将待排序列按某种规则分成**几个子序列**，并对这些子序列进行**直接插入排序**，当基本有序时再对全部进行一次直接插入排序。

> [!note] 执行过程
> 先将排序表分割成若干形如L[i,i+d,i+2d,...,i+kd]的特殊子表，对各个子表分别进行直接插入排序，缩小增量d，重复执行直到d为1为止。

→排序49,38,65,97,76,13,27,49，如初始d为4，每次缩量为d/2。

```c
void ShellSort(ElemType A[],int n){
    int d, i, j;
    for(d=n/2; d>=1; d=d/2)
        for(i=d+1; i<=n; ++i)
            if (A[i]<A[i-d])  {
                A[0]=A[i];
                for(j=i-d; j>0 && A[0]<A[j]; j-=d)
                    A[j+d]=A[j];
                A[j+d]=A[0];
            }
}
```

> [!tip] 总结
> 1. 空间复杂度为O(1)。
> 2. 时间复杂度和增量序列的选择有关，最坏时间复杂度为O(n²)。
> 3. 此算法不稳定。
> 4. 此算法仅适用于顺序表，不适用于链表。
