- 在表 L 的第 i 个位置上插入指定元素 e
```c
Status ListInsert(LinkList &L, int i, ElemType e){ // 在带头结点的单链表 L 中第 i 个位置插入值为 e 的新结点
    LNode *p=L;
    int j=0; // 当前 p 指向第几个结点
    while(p && (j<i-1)){
        p=p->next;
        ++j;
    } // 查找第 i-1 个结点，p 指向该结点
    if(!p || j>i-1) return ERROR; // i>n+1 或者 i<1，报错
    s=new LNode; // 生成新结点 *s
    s->data=e; // 将结点 *s 的数据域置为 e
    s->next=p->next; // 将结点 *s 的指针域指向结点 ai
    p->next=s; // 将结点 *p 的指针域指向结点 *s
    return OK;
}
```

### 指定插入
- 指定结点的**后插操作**：在指定结点p之后插入元素e，相当于已知前驱结点，直接插入即可
```c
Status InsertNextNode(LNode *p, ElemType e){
    if(p==NULL) return ERROR;
    LNode *s=(LNode *)malloc(sizeof(LNode)); // 生成新结点 *s
    if(s==NULL) return ERROR; // 内存分配失败
    s->data=e; // 将结点 *s 的数据域置为 e
    s->next=p->next; // 将结点 *s 的指针域指向结点 ai
    p->next=s; // 将结点 *p 的指针域指向结点 *s
    return OK;
}
```


- 指定结点的**前插操作**：在指定结点p之前插入元素e，此时未知前驱结点
- 先把e后插到p后面，再交换e和p的数据域
```c
Status InsertPriorNode(LNode *p, ElemType e){
    if(p==NULL) return ERROR;
    LNode *s=(LNode *)malloc(sizeof(LNode)); // 生成新结点 *s
    if(s==NULL) return ERROR; // 内存分配失败
    s->next=p->next; // 将结点 *s 的指针域指向结点 ai
    p->next=s; // 将结点 *p 的指针域指向结点 *s
    s->data=p->data; // 将 p 中元素复制到 s
    p->data=e; // p 中元素覆盖为 e
    return OK;
}
```
