- **初始化：**
- 约定创建空队列时，令 `front = rear = 0`。

```cpp
void InitQueue(SqQueue &Q) {
    Q.rear = Q.front = 0;
}
```

- **入队：**
- 在队尾插入，所以与尾指针相关。

```cpp
Status EnQueue(SqQueue &Q, ElemType x) {
    if (队列满了)
        return ERROR; // 队满报错
    Q.data[Q.rear] = x; // 将 x 插入队尾
    Q.rear = Q.rear + 1; // 队尾指针后移
    return OK;
}
```

- **出队：**
- 在队头删除，所以与头指针有关。

```cpp
Status DeQueue(SqQueue &Q, ElemType &x) {
    if (队空了)
        return ERROR; // 队空报错
    x = Q.data[Q.front]; // 将队头元素取出
    Q.front = Q.front + 1; // 队头指针后移
    return OK;
}
```

- **判空：**
- 与初始化状态一样，表示现在是空队列状态。

```cpp
bool QueueEmpty(SqQueue Q) {
    if (Q.rear == Q.front)
        return true;
    else
        return false;
}
```

【思考】刚才发现了一个问题，如果按照正常的逻辑实现基本操作会有问题，就是在明明队内还有空位的情况下，却表明溢出了，这就是“假溢出”。

即当 `rear == MaxSize` 时，队列不一定存满，分配的内存空间前面的位置还空闲，但是由于数组越界而导致程序的非法操作错误。

【how to solve】其实想想假溢出的过程，如果在最后溢出那一下，`rear` 能重新指向最开始的队头就好了。就和前面的循环链表一样搞成一个环，就好了。
