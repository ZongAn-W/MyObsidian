## 堆排序

> [!question] 思考
> 简单选择排序每次选最大or最小加入序列，但是需要**每次遍历一遍**。引入堆排序。

- **堆Heap的定义**：n个关键字序列L[1...n]称为堆，当且仅当该序列满足：
1. L(i)≥L(2i)且L(i)≥L(2i+1) （1≤i≤n/2）为**大根堆**(大顶堆);
2. L(i)≤L(2i)且L(i)≤L(2i+1) （1≤i≤n/2）为**小根堆**(小顶堆)。

> [!warning] 注意
> 可将堆看成一棵完全二叉树，任何一个非叶结点的值都不大于或不小于其左、右孩子结点的值，若父亲大孩子小，则为大根堆；若父亲小孩子大，则为小根堆。

> [!tip] 总结
> 调整序列成为一个大根堆：
> →根据大根堆根结点大于左右孩子结点的特性，判断出对于一个序列，只需要调整其对应完全二叉树中的**非终端结点**，看看是否满足大根堆的要求，而不需查看叶子结点。
> 1. 找到序列对应二叉树中，**最后一个分支结点**，判断其是否大于左右孩子，若不满足，则将当前结点与更**大的一个孩子互换**。
> 2. 当和孩子互换后，查看换下来的原**“根结点”**是否还为分支结点，如果是的话，查看是否还满足大于其左右孩子。
> 3. 依次向前遍历所有分支结点，将所有分支结点都调整符合性质后，则序列对应二叉树的根结点则为最大数值，此时序列为大根堆。

```c
void BuildMaxHeap(int A[],int len){    //建立大根堆
    for  (int i=len/2; i>0; i--) //从后往前调整所有分支结点
        HeadAdjust (A, i, len);
}

//函数 HeadAdjust 将元素k 为根的子树进行调整
void HeadAdjust(int A[], int k, int len){
    A[0]=A[k];    //A[0]暂存子树的根结点
    for(int i=2*k; i<=len; i*=2){  //沿key较大的子结点向下选
        if( i<len && A[i]<A[i+1]) //当i=len则没有右孩子
            i++; //取 key较大的子结点的下标
        if (A[0]>=A[i])  break; //筛选结束
        else{
            A[k]=A[i]; //将 A[i]调整到双亲结点上
            k=i; //修改k值，以便继续向下筛选
        }
    }
    A[k]=A[0]; //被筛选结点的值放入最终位置
}
```

> [!tip] 总结
> 堆排序过程：
> 1. **建堆**，建立原始序列对应的完全二叉树顺序序列，将这个序列调整为一个**大根堆**。
> 2. 先将大根堆堆顶关键字和**序列最后一个关键字（树中最后叶结点）**交换，然后将剩余关键字重新调整为**大根堆**，继续与最后一个关键字交换，再进行调整，反复执行到只剩一个结点时排序结束。

```c
void HeapSort(ElemType A[],int len){
    BuildMaxHeap(A,len);      //初始建堆
    for(i=len;i>1;i--){      //n-1趟的交换和建堆过程
        Swap(A[i],A[1]);      //输出堆顶元素（和堆底元素交换）
        HeadAdjust(A,1,i-1);      //调整，把剩余的i-1个元素整理成堆
    }
}
```

- **时间复杂度**：
   - →分析整个堆排序的过程主要分为**建堆**、循环调整产生**排序**两个过程。
   - →两个过程都依赖**HeadAdjust**调整函数。
   - 每次结点调整一层，最多关键字比较2次（一次左右孩子选最大，一个根结点和最大孩子比）。
   1. 建堆的过程，关键字对比次数不超过4n，建堆时间复杂度为O(n)。
   2. 排序的过程总共需要n-1趟，当堆顶和最末交换后，最末需要调整，最多需要被调整h-1层，每次往下调整一层，最多比较关键字2次。所以每一趟排序复杂度不超过O(h)=O(log₂n)。
   - 又因为需要n-1趟的排序，总时间复杂度为O(nlog₂n)。
- **空间复杂度**：O(1)。
- **稳定性**：不稳定。
- **堆的插入**：需要在插入结点后**保持堆的性质**，即完全二叉树形态与父大子小的性质（以大顶堆为例），因此需要先将将要插入的结点x放在**最底层的最右边**，插入后满足完全二叉树的特点；然后把x**依次向上**调整到合适位置以满足父大子小的性质。
- **堆的删除**：被删除的元素用**堆底元素**替代，然后让该元素不断调整到合适的位置。
