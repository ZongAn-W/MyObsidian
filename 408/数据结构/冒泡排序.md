## 冒泡排序

```c
void swap(int &a, int &b){
    int temp=a;
    a=b;
    b=temp;
}
void BubbleSort(ElemType A[], int n){
    for(int i=0; i<n-1; i++){
        bool flag=false;
        for(int j=n-1; j>i; j--)
            if(A[j-1]>A[j]){
                swap(A[j-1],A[j]);
                flag=true;
            }
        if(flag==false)
            return;
    }
}
```

- **空间复杂度**：O(1)。
- **时间复杂度**：
   - **最好情况**：序列原本有序的情况下，只需要一趟冒泡，比较n-1次即可。最好时间复杂度为O(n)。
   - **最坏情况**：序列原本逆序的情况下，比较次数和交换次数都为n(n-1)/2。最坏时间复杂度为O(n²)。
   - **平均时间复杂度**为O(n²)。
- **稳定性**：稳定。
- **适用**：顺序表和链表都可。
