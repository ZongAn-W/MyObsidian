这篇是 CVPR 2019 的 **SPADE**，目标是“语义分割图到真实图像”的条件生成：

\[ \text{语义标签图} \rightarrow \text{照片级图像} \]

例如给定“天空、树、草地、道路”的像素级布局，生成一张结构严格对应的自然图像。

核心贡献不是新 GAN 损失，而是新的归一化层：**Spatially-Adaptive (DE)normalization，SPADE**。

**它想解决的问题**

早期方法通常把分割图输入生成器开头，之后经过卷积、InstanceNorm/BatchNorm 和非线性层逐步生成图像。

问题在于：归一化会抹去特征的均值和方差。如果某一位置的语义信息刚好主要体现在激活强度上，归一化后该信息会被冲淡甚至消失。尤其对于大面积、标签均匀的区域，生成器可能无法区分“这里是天空”还是“这里是草地”。

SPADE 的做法是：**不只在输入端给一次分割图，而是在生成器的每一个归一化层中持续注入分割图。**

**SPADE 层**

普通归一化层先对某层特征 \(h\) 标准化：

$\hat h_{n,c,y,x} = \frac{h_{n,c,y,x}-\mu_c}{\sigma_c}$

常规 BatchNorm 的缩放和偏置是每个通道一个标量：

$h'_{n,c,y,x} = \gamma_c\hat h_{n,c,y,x}+\beta_c$

SPADE 将它改成空间位置相关的参数：

$h'_{n,c,y,x} = \gamma_{c,y,x}(m)\hat h_{n,c,y,x} + \beta_{c,y,x}(m)$

其中：

- m：输入语义分割图；
- $\gamma_{c,y,x}(m)、\beta_{c,y,x}(m)$：由分割图计算得到；
- 它们的尺寸是 `C × H × W`，而非普通归一化里的 `C`；
- 因此同一个通道在不同像素位置可以有不同调制方式。

直观说，归一化会先把特征“清零、标准化”，SPADE 再根据当前位置属于天空、树、人还是道路，给该位置恢复不同的缩放和偏移。语义布局因而不会在网络深层丢失。

**$\gamma$ 和 $\beta$ 怎样生成**

对每一个 SPADE 层：

1. 将原始分割图缩放到该层特征图的分辨率；
2. 将标签图嵌入为特征表示；
3. 用一个小卷积网络处理；
4. 输出该层所需的两组空间调制参数$\gamma$ 和 $\beta$ 

论文采用两层卷积网络来从语义图产生这些参数，核心卷积核为 `3×3`。消融实验表明，若用 `1×1` 卷积，缺少邻域语义上下文，性能会下降。

**生成器结构**

它使用纯解码器式生成器，而不是经典的“编码分割图再解码”的结构：

```
随机潜变量 z（或低分辨率语义图）
        ↓
SPADE ResBlock + 上采样
        ↓
SPADE ResBlock + 上采样
        ↓
...
        ↓
RGB 图像
```

每个 SPADE ResBlock 内的归一化都由对应尺度的分割图控制。随着分辨率提升，分割图也同步下采样到相应尺度。

这意味着：

- 生成器起点可以使用随机向量 \(z\)；
- 分割图不必作为普通输入在网络中传递；
- 即使 \(z\) 不携带布局信息，各层 SPADE 也不断提供位置语义；
- 同一个分割图配不同 \(z\)，可生成结构相同、纹理/光照/风格不同的图像。

**训练方式**

整体仍是条件 GAN：

- 生成器 \(G(m,z)\)：由语义图 \(m\) 和随机向量 \(z\) 生成图像；
- 多尺度判别器：在不同图像尺度判别生成结果是否真实、是否符合对应语义图；
- 对抗损失：将 pix2pixHD 中的最小二乘 GAN 损失替换为 hinge loss；
- 其余沿用 pix2pixHD 的训练目标，包括判别器特征匹配损失和 VGG 感知损失；
- 生成器与判别器均采用 Spectral Normalization；
- 使用 Adam，生成器和判别器学习率分别为 $10^{-4} 与 4\times10^{-4}$

**多模态与风格控制**

基础 SPADE 可以直接采样随机 \(z\) 实现多样化生成。论文还增加一个可选图像编码器：

$x_{\text{style}} \rightarrow E(x_{\text{style}})=z$

训练时，编码器把真实图像编码为潜变量，SPADE 生成器据此重建图像，并加 KL 散度约束，使潜变量空间接近正态分布。测试时可：

- 采样不同随机 \(z\)：得到不同外观；
- 输入一张参考风格图：提取其 \(z\)，把整体色调、光照、天气等风格迁移到指定语义布局上。

**它与“直接拼接通道”不同**

和你上一篇论文里“地形图直接作为通道拼接”相比，SPADE 更强：

|方法|条件信息如何进入网络|
|---|---|
|直接通道拼接|将条件图与特征图 concat，再交给卷积自己学习|
|SPADE|每层归一化后，用条件图生成逐像素的 \(\gamma,\beta\) 来显式调制特征|

论文消融也显示：即使在每层都拼接分割图，效果仍明显弱于 SPADE。原因是拼接后的语义信息仍可能被后续归一化冲淡，而 SPADE 本身就在归一化之后注入条件。

一句话总结：**SPADE 用语义图在每一层、每一个空间位置控制归一化后的特征，因此既保留了像素级布局，又允许随机潜变量控制图像外观。**
