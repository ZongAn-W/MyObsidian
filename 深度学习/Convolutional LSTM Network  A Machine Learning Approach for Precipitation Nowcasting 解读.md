# 《Convolutional LSTM Network: A Machine Learning Approach for Precipitation Nowcasting》解读

论文：Xingjian Shi 等，NIPS 2015  
核心贡献：提出 ConvLSTM，将 LSTM 的全连接运算替换为卷积运算，用于预测未来的雷达回波图。

一句话概括：

> ConvLSTM 让模型同时记住“过去发生了什么”和“事情发生在哪里”，因此比普通 FC-LSTM 更适合预测云团和降雨的空间移动。

## 1. 论文要解决什么问题？

降雨临近预报是指根据最近一段时间的雷达回波图，预测未来几十分钟到几小时的降雨分布。

输入不是普通的时间序列，而是：

```
过去的雷达图序列
    ↓
未来的雷达图序列
```

每一张雷达图既有空间结构，又随时间变化。因此模型必须同时学习：

- 降雨区域在哪里；
- 云团向哪个方向移动；
- 降雨强度如何增强或减弱；
- 新的降雨系统是否会从边界进入。

传统 ROVER 方法主要使用光流估计运动，再将雷达回波向未来平移。它擅长描述“移动”，但难以学习云团的生成、消散和合并。

## 2. 为什么普通 FC-LSTM 不够好？

普通 LSTM 假设输入是向量。如果把一张雷达图展平成向量：

```
100 × 100 图像 → 10000 维向量
```

会产生两个问题：

1. **空间位置关系被破坏**  
    相邻像素在向量中可能只是相邻元素，模型没有明确的局部空间先验。
    
2. **参数量巨大**  
    每个位置都与大量隐藏单元全连接，参数冗余严重，训练困难。
    

FC-LSTM 可以理解时间关系，但不擅长处理“一个降雨区域向右移动”这种空间运动模式。

## 3. ConvLSTM 的核心思想

普通 LSTM 的关键计算是：

$W_x x_t + W_h h_{t-1}$

ConvLSTM 将其替换为：

$W_x * X_t + W_h * H_{t-1}$

其中 `*` 表示卷积。

也就是说：

- 输入 $X_t$保持为二维空间网格；
- 隐状态 $H_t$和记忆单元 $C_t$ 也保持为空间网格；
- 输入到状态的连接使用卷积；
- 状态到状态的连接也使用卷积；
- 输入门、遗忘门、输出门仍然控制信息的写入、保留和输出。

因此，某个位置的未来状态主要由它附近区域决定，而不是由整张图的所有位置决定。

可以这样理解：

```
普通 LSTM：每个位置和全局所有位置连接
ConvLSTM：每个位置和局部邻域连接
```

卷积核大小也很重要。论文发现：

- `1 × 1` 状态转移几乎不能传播空间运动；
- `3 × 3`、`5 × 5` 等较大卷积核可以让信息在空间上逐步传播；
- 因此，ConvLSTM 的状态转移卷积核不能简单设为 `1 × 1`。

论文还指出，FC-LSTM 可以看作 ConvLSTM 的特殊情况：空间维度退化为 `1 × 1`。

## 4. 编码器-预测器结构

论文使用了一个编码-预测结构：

```
历史雷达图
    ↓
Encoding ConvLSTM
    ↓
压缩成隐藏状态和记忆状态
    ↓ 复制状态
Forecasting ConvLSTM
    ↓
未来雷达图序列
```

编码网络读取过去的多帧图像，提取运动和演化规律。预测网络从编码网络的最终状态开始，逐步生成未来帧。

最后用 `1 × 1` 卷积把隐藏状态映射为预测雷达图。

这种结构本质上是一个面向空间序列的 sequence-to-sequence 模型。

## 5. Moving-MNIST 实验

作者先在合成数据上验证模型。

数据特点：

- 图像大小：`64 × 64`；
- 两个数字在图像中移动、碰撞、遮挡；
- 每个序列 20 帧；
- 前 10 帧作为输入，后 10 帧作为预测；
- 训练集 10000 个序列，验证集 2000 个，测试集 3000 个。

测试结果如下，交叉熵越低越好：

|模型|参数量|交叉熵|
|---|---|---|
|FC-LSTM|142.7M|4832.49|
|1 层 ConvLSTM|13.5M|3887.94|
|2 层 ConvLSTM|10.0M|3733.56|
|3 层 ConvLSTM|7.6M|3670.85|

主要结论：

- ConvLSTM 明显优于 FC-LSTM；
- 参数量只有 FC-LSTM 的约 1/19；
- 更深的网络效果更好，同时参数更少；
- 使用 `1 × 1` 状态转移的模型明显变差。

这说明 ConvLSTM 的优势主要来自正确的空间结构，而不是单纯增加网络规模。

在“域外”测试中，模型面对三个数字而不是训练时的两个数字，仍然可以大致预测运动方向和数字分离，但图像变得模糊。这说明模型学到了部分运动规律，但预测存在不确定性。

## 6. 香港雷达回波实验

数据来自香港 2011 至 2013 年的雷达记录：

- 选择 97 个降雨较多的日期；
- 每 6 分钟记录一帧；
- 图像裁剪、滤波并缩放为 `100 × 100`；
- 输入 5 帧，预测未来 15 帧；
- 即用过去 30 分钟预测未来 90 分钟；
- ConvLSTM 使用两层、每层 64 个隐藏状态、`3 × 3` 卷积核。

结果如下：

|模型|Rainfall-MSE|CSI|FAR|POD|Correlation|
|---|---|---|---|---|---|
|ConvLSTM|**1.420**|**0.577**|**0.195**|**0.660**|**0.908**|
|ROVER1|1.712|0.516|0.308|0.636|0.843|
|ROVER2|1.684|0.522|0.301|0.642|0.850|
|ROVER3|1.685|0.522|0.301|0.642|0.849|
|FC-LSTM|1.865|0.286|0.335|0.351|0.774|

ConvLSTM 在所有主要指标上都最好：

- 降雨量误差最低；
- CSI 最高；
- 虚警率 FAR 最低；
- 探测率 POD 最高；
- 空间相关性最高。

ROVER 的预测通常更锐利，但容易产生更多虚警。ConvLSTM 的结果略有模糊，却更接近真实降雨轮廓，尤其在图像边界处表现更好。

## 7. 为什么 ConvLSTM 能超过 ROVER？

论文给出两个主要原因。

### 第一，能够学习复杂的非线性变化

ROVER 主要进行光流估计和回波平移，默认运动规律相对稳定。

ConvLSTM 可以直接从数据中学习：

- 云团合并；
- 云团消散；
- 降雨强度变化；
- 边界处的新降雨系统；
- 非匀速和非线性运动。

### 第二，可以端到端训练

ROVER 的运动估计和未来传播是分开的，难以整体优化。

ConvLSTM 从输入雷达图直接训练到未来雷达图：

```
输入 → 隐状态 → 预测
```

所有参数都围绕最终预测目标联合优化。

## 8. 论文最重要的贡献

这篇论文的真正创新不是“把 LSTM 和 CNN 简单拼起来”，而是：

1. 将 LSTM 的输入到状态和状态到状态连接都改成卷积；
2. 让记忆状态本身保留空间结构；
3. 用编码-预测结构处理多步未来预测；
4. 证明局部空间归纳偏置对于时空预测非常重要；
5. 将深度学习正式引入雷达降雨临近预报。

它后来成为视频预测、交通流预测、气象预测等领域的重要基础结构。

## 9. 局限性

这篇论文也有一些明显限制：

- 实验数据主要来自香港，跨地区泛化能力没有验证；
- 论文目标提到可预测 1-6 小时，但雷达实验实际只预测未来 90 分钟；
- 训练集、测试集可能来自同一天，作者也承认存在一定数据依赖；
- 模型输出是单一确定性预测，无法表达“未来可能有多种演化路径”；
- 长时间预测会出现误差累积和图像模糊；
- 只使用雷达回波，没有融合风场、地形、数值天气预报等物理信息；
- 使用像素级交叉熵训练，但业务评价还包括降雨量误差和阈值技能分数，训练目标与实际业务目标并不完全一致。

## 10. 最值得记住的一句话

> FC-LSTM 只能记住“发生了什么”；ConvLSTM 同时记住了“发生了什么”和“发生在哪里”。
