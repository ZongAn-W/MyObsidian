# 引用（reference）

> 一句话：引用是已有变量的**别名**，必须初始化、不能改绑、不能为空。`T&` 与 `T` 是不同类型，但操作引用就是操作它绑定的对象。

## 1. 引用是什么

```cpp
int x = 10;
int& r = x;          // r 是 x 的别名（r 绑定到 x）

r = 20;              // 等价于 x = 20
std::cout << x;      // 20

std::cout << (&r == &x);   // 1：引用取地址就是被引用对象的地址
```

> 说明：本文示例为突出语法省略了 `#include`，完整编译通常需要 `<iostream>`、`<string>`、`<vector>`、`<ostream>`、`<utility>` 等头文件。

- 引用**不是独立对象**，不占独立存储（具体实现通常是地址，可能被编译器优化掉）；
- 对引用做的一切操作，实际都作用在被引用的对象上；
- 类型读法：`int&` 是「到 int 的引用」，`const int&` 是「到 const int 的引用」。

## 2. 三条铁律

1. **必须初始化**：`int& r;` 编译错误。
2. **不能改绑**：`r = y;` 是把 `y` 的值赋给 `r` 绑定的对象，不是让 `r` 指向 `y`。
3. **不能为空**：不存在合法的「空引用」。`int& r = *p;`（`p` 为 `nullptr`）是未定义行为。

```cpp
int a = 1, b = 2;
int& r = a;
r = b;            // a 变成 2，r 仍然绑定 a，不会改绑到 b
```

## 3. 引用 vs 指针

| 对比项 | 引用 `T&` | 指针 `T*` |
| --- | --- | --- |
| 是否必须初始化 | 必须 | 可以先声明，后赋值 |
| 能否为空 | 不能 | 可以为 `nullptr` |
| 能否改绑 | 不能 | 可以重新指向 |
| `sizeof` 结果 | 被引用对象的大小 | 指针本身的大小 |
| `++` 的含义 | 对象自增 | 地址偏移 |
| 能否有多级 | 声明中不能直接写「引用的引用」，但 `typedef`/模板可能折叠出引用（C++11 起按引用折叠规则坍缩为单个引用） | 可以有多级指针 |
| 使用前检查 | 不需要 | 常需要判空 |
| 主要用途 | 函数参数/返回值、别名 | 可选指向、动态内存、数组/链表 |

经验：**能用引用就用引用**（更安全、语法更自然）；需要表示「可能为空」或「需要改指向」时用指针。

## 4. 引用的典型用法

### 4.1 函数参数：避免拷贝、支持修改

```cpp
void swap(int& a, int& b) {     // 传入并修改实参
    int t = a; a = b; b = t;
}

void print(const std::string& s);   // 只读大对象：不拷贝，且能接受临时量
```

- `T&`：需要修改实参，或需要「输出参数」；
- `const T&`：只读、大对象避免拷贝，还能绑定临时对象/字面量；
- 小对象（`int`、`double`、指针）按值传往往更快，没必要用 `const&`。
- 传大对象按值会触发拷贝，这是函数调用开销的重要部分，见 [[函数调用的成本]]；

### 4.2 const 引用与临时对象

```cpp
void f(const std::string& s);

f("hello");       // 字面量先构造临时 std::string，再绑定到 const 引用

const std::string& name = std::string("C++");   // 临时对象生存期延长到 name 的作用域结束
```

- **生存期延长**只发生在：临时对象绑定到局部的 `const T&` 或 `T&&` 引用；
- 函数参数的 `const T&` 不把临时对象延长到调用者作用域：函数返回后不要保存该引用，否则悬垂。

### 4.3 返回引用

```cpp
class Buffer {
    std::vector<int> data;
public:
    int& operator[](std::size_t i) { return data[i]; }   // 返回内部元素的引用
    const int& operator[](std::size_t i) const { return data[i]; }

    void push_back(int v) { data.push_back(v); }
};

Buffer buf;
buf.push_back(0);   // 先放入一个元素，否则 buf[0] 越界
buf[0] = 42;        // 通过返回的引用修改内部元素
```

返回引用合法的对象：

- 调用者传入的对象（参数引用）；
- 类的成员、`*this`（如 `operator=`、`operator<<` 返回 `*this`）；
- 静态对象、堆对象、全局对象。

**禁止**返回局部变量或临时对象的引用：

```cpp
int& bad() {
    int x = 1;
    return x;       // ❌ x 在函数结束时销毁，返回值是悬垂引用
}
```

### 4.4 引用成员

```cpp
class Logger {
    std::ostream& out;                                   // 引用成员
public:
    explicit Logger(std::ostream& os) : out(os) {}       // 必须在初始化列表绑定
    void log(const std::string& msg) { out << msg << '\n'; }
};
```

- 引用成员必须在构造函数**初始化列表**中初始化；
- 有引用成员的类，默认拷贝赋值运算符会被 `delete`（无法给引用改绑），需要手写赋值逻辑。

### 4.5 数组引用、函数引用、指针的引用

```cpp
int arr[3] = {1, 2, 3};
int (&ra)[3] = arr;              // 数组的引用

void func(int) {}
void (&rf)(int) = func;          // 函数的引用

void reset(int*& p) {            // 指针的引用：可以修改调用者的指针
    p = nullptr;
}
```

数组引用在模板里很有用，能自动推导数组长度：

```cpp
template <std::size_t N>
constexpr std::size_t size_of(int (&)[N]) { return N; }
```

## 5. const 与引用的绑定规则

| 引用类型 | 能绑定左值 | 能绑定 const 对象 | 能绑定字面量/临时量 |
| --- | --- | --- | --- |
| `int&` | ✅ | ❌ | ❌ |
| `const int&` | ✅ | ✅ | ✅ |
| `int&&` | ❌ | ❌ | ✅（右值） |

```cpp
int a = 1; const int b = 2;

int& r1 = a;        // ✅
// int& r2 = b;     // ❌ 不能用非 const 引用绑定 const 对象
const int& r3 = b;  // ✅
const int& r4 = 42; // ✅ 临时量 → const 引用
// int& r5 = 42;    // ❌ 非 const 引用不能绑字面量
```

const 引用与非 const 引用可以构成函数重载：

```cpp
void f(int&);          // 左值版本
void f(const int&);    // const 对象/临时量版本
```

## 6. 右值引用与移动语义（C++11 进阶）

```cpp
std::string a = "hello";
std::string b = std::move(a);   // 把 a 的内部资源转移给 b，避免深拷贝
// a 仍然有效，但值「未指定」（通常为空）
```

- `T&&` 是**右值引用**，只能绑定右值（临时对象、`std::move` 的结果）；
- `std::move` 本身不移动任何东西，只是一次 `static_cast<T&&>` 类型转换；
- 移动构造/移动赋值接受 `T&&`，用于「窃取」资源；
- 模板里的 `T&&`（`T` 需要推导时）是**转发引用/万能引用**，配合 `std::forward<T>` 实现完美转发：

```cpp
template <typename T>
void wrapper(T&& arg) {
    target(std::forward<T>(arg));   // 保持 arg 原来的值类别
}
```

- 引用折叠规则：`&` + `&&` → `&`，`&&` + `&&` → `&&`；
- 注意：右值引用变量本身是**左值**——`int&& rr = 1;` 之后，`rr` 有名字，是左值。

## 7. 常见坑

1. **返回局部变量/临时量的引用** → 悬垂引用，未定义行为；
2. **保存函数 `const T&` 参数的引用** → 函数返回后临时对象销毁，悬垂；
3. **`auto` 丢失引用**：`auto x = r;` 是拷贝，`auto& x = r;` 才保留引用；
4. **容器不能装引用**：`std::vector<int&>` 不合法，改用 `std::reference_wrapper<int>` 或指针；
5. **范围 for 的拷贝陷阱**：`for (auto x : v)` 每个元素拷一份；要改元素用 `auto&`，只读用 `const auto&`；
6. **引用成员使默认赋值被删除**；
7. **不存在空引用**：需要「可能没有」的语义时用指针或 `std::optional`。

```cpp
std::vector<int> v = {1, 2, 3};
for (auto x : v)  { x *= 2; }              // ❌ 改的是副本
for (auto& x : v) { x *= 2; }              // ✅ 改原元素
```

## 8. 怎么选：引用还是指针

- 函数参数：要修改 → `T&`；只读大对象 → `const T&`；可能为空/可选 → `T*`；
- 返回值：优先按值返回（C++17 起纯右值返回的 RVO 是强制的，NRVO 由编译器决定）；需要链式调用或访问内部对象时才返回引用；
- 类成员：引用成员要求「构造时必须存在」，可选成员用指针/`std::optional`；
- 指针用于：动态内存、链表/树节点、需要改指向、表示「无」。

## 9. 面试高频

| 问题 | 要点 |
| --- | --- |
| 引用占内存吗？ | 语义上不是对象；实现通常是地址，可能被优化掉。不要回答「一定占 4/8 字节」 |
| 引用可以为空吗？ | 合法程序中不能；空指针解引用得到「空引用」是未定义行为 |
| 引用可以改绑吗？ | 不能，`r = y` 是赋值 |
| `const T&` 绑临时对象会怎样？ | 局部 `const T&` 会延长临时对象生存期 |
| 返回引用要注意什么？ | 不能返回局部变量/临时对象的引用 |
| `int&&` 是左值还是右值？ | 右值引用变量本身是左值 |
| `std::move` 之后对象还能用吗？ | 能（有效但值未指定），通常只做赋值/析构 |

## 10. 小结

- 引用 = 别名：必须初始化、不能改绑、不能为空；
- 参数：`T&` 用于修改，`const T&` 用于只读且可绑临时量；
- 返回引用要保证被引用对象活得比引用久；
- 内联函数常用 `const T&` 参数避免大对象拷贝，见 [[内联函数]]；
- 标准库工具 `std::move`、`std::forward` 位于 `std::` 命名空间，见 [[命名空间]]。

- [[内联函数]]：内联函数体在调用点展开，参数用 `const T&` 可避免大对象拷贝；
